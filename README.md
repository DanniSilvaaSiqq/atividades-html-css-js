# 🌐 Meus Estudos: Desenvolvimento Web Completo

Bem-vindo ao meu repositório de estudos! 🚀 

Este espaço é dedicado a armazenar e organizar todas as minhas atividades, anotações e projetos práticos focados em **HTML, CSS e JavaScript**. Ele funciona como o meu portfólio de evolução contínua na área de programação.

## 📖 Sobre o Repositório

Atualmente, sou estudante do curso **"Desenvolvimento Web Completo - 20 cursos + 20 projetos"**. Estou a utilizar este repositório para documentar o meu progresso módulo a módulo, desde a estruturação básica de páginas até à criação de aplicações completas.

> 🚧 **Status:** Em desenvolvimento ativo. Estou a construir a minha base de conhecimento dia após dia!

## 🛠️ Tecnologias e Trilha de Aprendizagem

Este repositório reflete a minha jornada de estudos. Abaixo estão as tecnologias e conceitos que estou a explorar e a dominar:

**Front-End (Interface e Estilização):**
*   **HTML5:** Estrutura básica, semântica, formulários e mídias.
*   **CSS3:** Estilização avançada, FlexBox e Grid Layout.
*   **Frameworks de CSS:** Bootstrap 5 e pré-processadores como SASS.
*   **JavaScript & ES6+:** Lógica de programação, manipulação da DOM e Orientação a Objetos.

**Back-End e Banco de Dados (Próximos Passos):**
*   **PHP (7 e 8):** Sintaxe, PDO e Padrão de arquitetura MVC.
*   **Banco de Dados:** MySQL para armazenamento e gestão de dados.
*   **Integrações:** Ajax, jQuery e criação de APIs com Slim Framework.

**Extras do Curso:**
*   Aplicações Mobile com IONIC e gestão de conteúdo com WordPress.

## 🤖 Automação Integrada

Como bônus de produtividade, integrei neste repositório o script `backup.py`, um **robô de automação construído em Python**. Ele é responsável por varrer as minhas pastas de estudo (como a `htmlaulas`), identificar novos códigos, criar os commits e fazer o push de forma 100% automatizada para o GitHub!
